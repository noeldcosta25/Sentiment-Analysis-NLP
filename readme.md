**Sentiment Analysis using NLP Technique**

This project focuses on analyzing the sentiment of textual data using Natural Language Processing techniques. A Twitter dataset was used for training and evaluation. Initially, deep learning models such as LSTM and Bi-LSTM were implemented to understand sequential context in the text. Later, a transformer-based BERT model was applied, which significantly improved the prediction performance compared to the previous models. After comparative analysis, BERT was selected as the final model due to its higher accuracy and better contextual understanding.

The system performs text preprocessing, tokenization, and model inference to classify user input into positive or negative sentiment in real time. This project demonstrates practical experience in NLP, model comparison, and selecting an optimal architecture based on performance metrics.
